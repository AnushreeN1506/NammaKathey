## 📌 Project Overview

**Namma-Kathey** is an Android application developed using **Kotlin** and **Android Studio** that digitally preserves and showcases the inspiring stories of Karnataka’s regional heroes.

The application provides an engaging learning experience through:

* District-wise hero categorization
* Interactive story reading
* Image-based story cards
* Quiz-based learning
* Modern Material Design UI
* Offline support

The project focuses on promoting **cultural awareness**, **digital storytelling**, and **regional heritage preservation** using a user-friendly Android application.

---

# 🎯 Problem Statement

Many regional heroes, freedom fighters, poets, and cultural icons from Karnataka are gradually becoming unknown to younger generations because their stories are not available in interactive and accessible digital formats.

Traditional learning methods mainly depend on textbooks and scattered internet resources, which often fail to engage students effectively. As digital learning becomes more popular, valuable cultural stories and regional heritage risk being forgotten.

**Namma-Kathey** solves this problem by providing a centralized Android application that presents Karnataka’s regional hero stories through interactive storytelling, visual story cards, quizzes, and a modern mobile learning experience.
